# 指标与执行契约

以下为V3.1研究初值，未回测优化；每次报告保存实际参数。价格窗口使用截至信号日t可得的同基准复权OHLC，成交量采用可比股数；交易价格、涨跌停检查使用不复权价及当日证券规则。

## 指标

- rN = C_t/C_(t-N)-1；RS_N = 个股rN减所属行业同期收益，N取5/20。行业固定一种当时可得分类，不事后选最强概念。
- TR = max(H-L, |H-C_prev|, |L-C_prev|)；ATR20取最近20个完整交易日TR简单平均。ATR非正或不足窗口则待验证。
- VR_t = V_t / median(V_(t-20)..V_(t-1))；分母不含当日且须为正。
- CLV = (C-L)/(H-L)，H=L时记缺失而非默认强势。
- 趋势：C_t >= MA60_t 且 MA60_t >= MA60_(t-5)。至少需要65日有效行情；近期上市不足窗口的票另列。
- 加速过滤：最近5日任一天实际收盘涨停，或r5>12%，或(C-MA20)/ATR20>2.5，任一满足移出潜伏池。涨停由当时规则/官方价格核验，不用固定10%推算全部股票。
- 试盘代理：最近10日存在VR在[1.5,3]、当天涨幅在[0,5%]且CLV>=0.6的交易日p。多个时取最近一个。该代理只说明量价活跃，不能证明主力建仓。
- 回踩承接代理：p后至少2个完整交易日；之后日成交量中位数低于V_p，最新收盘不低于试盘日低点L_p，且没有收盘跌破预先记录的结构支撑。不能把仅有单根上影认定为洗盘。

## 板块与环境

统一报告市场r5、涨跌家数、站上MA20比例、成交额相对前20日中位数，以及行业RS5/RS20和行业上涨家数占比。

研究防守开关：市场r5<0且站上MA20比例<35%，只输出观察、不升级“待确认”；缺少广度则环境未知，同样不升级。该开关是研究假设，需分环境检验。

板块资格：行业RS5>0且成分股站上MA20比例>=50%。没有合格行业时核心池为空；其他事件驱动候选只作待观察。轮动顺序不得写死成“科技必然切农业”。

## 状态与优先级

先检查交易/数据资格，再检查结构失效，再检查加速，最后判断阶段：

| 状态 | 可复核条件 |
|---|---|
| 待验证 | 关键数据/证券风险核验缺失或冲突 |
| 失效 | 收盘跌破预先冻结的结构支撑，或出现硬风险 |
| 已启动 | 触发加速过滤，或收盘已突破预先冻结的平台上沿 |
| 观察 | 有题材或低位，但趋势、试盘、承接、环境或空间条件不齐 |
| 蓄势 | 行业资格、趋势、试盘和承接通过，未加速，空间合格 |
| 待确认 | 蓄势条件全部通过，且距离预先冻结的平台上沿为0至1个ATR20，环境非防守 |

平台研究代理：试盘日前20日最高价为上沿、最低价为支撑，试盘确认时冻结。若平台过宽导致空间不合格则拒绝，不为入选缩窄支撑。人工识别平台需列日期区间、算法和理由，不能与自动代理混评。新平台必须记录重新建池日期。

## 空间与成交约束

记录计划参考价E、结构失效价S、最近阻力区下沿T，要求0<S<E<T。T从截至t可见的前高、反复受阻区或成交密集区识别，附区间及来源；不得为通过门槛上调目标。无可靠阻力信息则空间未知，不能宣称上方无套牢盘。

设总往返费用与滑点估计为每股k，结构空间比 RR=(T-E-k)/(E-S+k)。默认RR>=2且T-E>k才具核心资格；E初取收盘价，次日开盘跳空后重新计算。未提供费用时必须披露采用的费率、最低佣金、样例名义金额和滑点，称情景估算，不称可成交收益。未知k则只展示毛空间比，降为观察。

S不是保证成交的止损价，另列跳空、跌停无法退出的压力情景。日线信号最早下一交易日参与模拟；按交易所当时有效规则处理T+1、申报数量、涨跌幅、停复牌和费用。一字涨停买不到、一字跌停卖不掉，不按理论价强行成交。

确认动作与潜伏榜分开：盘后确认可采用收盘突破冻结上沿且VR>=1.5，但此时已经启动，移至确认跟踪项，禁止仍称潜伏候选。五日无进展则退出本轮观察并重筛；支撑失效不等待满五日。
